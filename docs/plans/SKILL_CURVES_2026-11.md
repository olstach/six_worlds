# Skill bonus curves (2026-11)

Generated by `tools/migrate_skill_curves.py`. Each skill stat used to be a 15-entry table (levels 11-15 repeated level 10). It is now a formula that keeps going: `PerkSystem.curve_value(spec, level)`.

- climb: L <= 5 -> `at_5 * L(L+1)/30`; L > 5 -> `at_5 + (at_10 - at_5) * (L-5)/5`
- steady: `base + at_10 * L/10`
- `integer` floors; `limit` bounds the result toward its own sign; no other cap.

The curve for each stat is whichever of climb/steady has the smaller maximum error over levels 1-10. `at_5` / `at_10` are the old table's values at 5 and 10, with two exceptions: `mana_cost_reduction` aims at -106.25 so the line reaches its -100 limit at level 9 as the old table did, and integer counts fit `base` and slope by search (levels 1 and 10 pinned).

**Largest difference over levels 1-10:** `thievery.trap_detection_pct` (curve `climb`), off by 8.

## Integer stats (floored)

`effect_duration_turns`, `party_max_companions`, `party_skill_check_bonus`. These are counts; for them `base` is fitted so levels 1 and 10 match the table. Every one had an all-whole table.
