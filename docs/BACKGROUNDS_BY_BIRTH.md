# Backgrounds by birth

Every background that names specific births, for the contradictions pass.
Backgrounds with no restriction are universal and are listed at the end.

94 backgrounds total. Only 3 are universal; 55 are locked to a single birth.

Realms are marked so cross-realm sharing is visible: a background available to
both a hell birth and an animal one is either deliberate or an oversight.
