# Backgrounds by birth

94 backgrounds. **17 are universal** — any birth may take them.
The rest name specific births and are listed below for the contradictions pass.

Universal is the default now: a background with an empty `available_races` is open to
everyone, so births added later inherit it automatically rather than being silently starved.
